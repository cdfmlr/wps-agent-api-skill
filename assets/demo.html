WPS 开放平台 API 实测

这份文档完全由 WPS 开放平台 API 生成：创建文件、写入 HTML、设置页眉页脚、添加批注，再下载为 DOCX。

结论：对于复杂 Office 文档，这套 API 比手写 python-docx 更接近 Word 的对象模型。

能力对比

能力 python-docx WPS API
段落 / 样式要拼 XML，样式兼容性一般insert 直接写，可带字体和段落格式
复杂表格需手写 table/tr/tcHTML 或 TABLE_FULL 一次生成
页眉页脚 / 批注 / 域支持有限或需要 hack原生 query/update/insert 接口

适用场景

  • 需要保留复杂版式的 DOCX 自动生成
  • 批量替换、批注、修订、目录、页码
  • PPT 形状/图表/动画、Excel/多维表格读写
